# 目标

将项目中的 fastjson 全部改为 fastjson2，fastjson 的安全问题太多。

## maven

```xml
<dependency>
    <groupId>com.alibaba.fastjson2</groupId>
    <artifactId>fastjson2</artifactId>
    <version>2.0.61</version>
</dependency>
```

你改了版本号，注意对应的 fastjson 实现也需要调整

## 移除 deep-copy 依赖

另外，你看一下 deep-copy。

实现原理应该也不难，可以移除外部的二方依赖，改为内置用 fastjson2 自己实现。

## 要求

然后保障目前的单元测试全部通过

将项目的 pom.xml 版本从 1.7.0 改为 1.7.1

CHANGE_LOG.md + README.md 中更新对应的版本说明
